## 🎮 Interacciones Disponibles

### Botones del Tutorial
```
[← Anterior]  [Siguiente →]  [Cerrar ✕]
```

### Navegación
- **Clic en "Siguiente"**: Avanza al siguiente paso
- **Clic en "Anterior"**: Retrocede al paso anterior
- **Clic en "Cerrar" (✕)**: Cancela el tutorial
- **Presionar ESC**: Cancela el tutorial
- **Clic fuera del overlay**: Avanza al siguiente paso (opcional)

### Reiniciar Tutorial
- Presiona el botón **"Ver Tutorial"** en el encabezado
- Se reinicia desde el paso 1

## 🔄 Experiencia del Usuario

### Primera Visita
```
1. Usuario accede al dashboard
   ↓
2. Después de 500ms, el tutorial inicia automáticamente
   ↓
3. Se muestra el primer paso con overlay
   ↓
4. Usuario puede:
   • Avanzar con botón "Siguiente"
   • Retroceder con botón "Anterior"
   • Cerrar con botón "Cerrar" o ESC
   ↓
5. Al finalizar:
   • Se guarda en localStorage
   • No vuelve a mostrar automáticamente
```

### Visitas Posteriores
```
1. Usuario accede al dashboard
   ↓
2. Tutorial NO se inicia automáticamente
   ↓
3. Botón "Ver Tutorial" disponible en encabezado
   ↓
4. Usuario puede presionar el botón para reiniciar
```

## 🛠️ Personalización Rápida

### Cambiar el orden de los pasos
Simplemente reordena los objetos en el array `steps` del tutorial

### Agregar más pasos
```typescript
// En student-tutorial.tsx o teacher-tutorial.tsx
{
  element: '.nuevo-elemento',
  popover: {
    title: 'Nuevo Paso',
    description: 'Descripción',
    side: 'bottom',
    align: 'start'
  }
}
```

### Cambiar el color del popover
En `globals.css`:
```css
.driver-popover {
  @apply bg-yellow-100; /* Nuevo color */
}
```

### Cambiar el tiempo de inicio
En el `useEffect`:
```typescript
setTimeout(() => {
  tutorialButton.click()
}, 1000) // Cambiar 500 a 1000
```
